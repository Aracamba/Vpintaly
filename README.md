# Vpintaly
- Удобный инструмент для синхронизации конфигураций различных приложений.
Поддерживает протоколы vless:// vmess:// ss:// trojan:// vpn://, а так же подписки через https://
- Получение и обновление конфигураций происходит через общедоступные документы googledocs
## Настройка документа GoogleDocs 
- Настроить общий доступ
- Четко выделить конфигурацию с помощью указателя. Пример указателя: "устройство/подписка" + "Название"(Название обязательно должно быть одним словом): конфигурация. ВАЖНО! Для конфигураций типа vpn:// вместо названия конфигурации следует указывать именно числовое значение.
- Дальше работает только ваша фантазия. Вы можете украсить документ как угодно.
- [Шаблон для более понятного принципа работы](https://docs.google.com/document/d/1zfKsJc7a6oH1txkm2iqSu1BFs23-T5B8S9kKSxRfPO4/edit?usp=sharing)
## Настройка приложения
- Перейти в настройки и выбрать там Vpn клиент из доступных
- Перейти на главную страницу, подключить гугл и вставить ссылку на гугл документ. <details> <summary>Проблема</summary> (На этом шаге появляется огромная проблема. Проект в консоли гугл клоуд числится как находящийся в тестовом режиме, т.е без добавления в тестировщиков подключить гугл вы не сможете. Верифицировать его у меня нет ни желания, ни времени, ни юр образования. Если кто-то захочет помочь с этим - пишите мне на почту: nikolichevvit@gmail.com) </details> 
- Нажать кнопку "Проверить статус конфигурации".
- После успешной проверки нажать на кнопку "Передать конфигурации в VPN"
- Все конфигураци будут отправлены в выбранные впн клиенты.
## Для кого может быть полезно это приложение
-Компании друзей, решившие скинуться деньгами и купить vps сервер, после чего накатив туда тот же 3x-ui. Все конфигурации находятся в одном месте и удобно меняются/добавляются. В принципе это все кому может понадобится это приложение.
